# Ravi Kumar — AI/ML Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript to showcase AI/ML, Generative AI, RAG, and Python project work.

## Run locally

No build step or package installation is required.

1. Download or clone this repository.
2. Open `index.htm` in a browser, or use VS Code Live Server.
3. The site loads Google Fonts over the internet; system fonts are used as fallbacks.

## Sections

- Introduction and role focus
- About and education
- Technical skills
- Selected projects
- Internship and certification timeline
- Contact links

## Tech stack

- HTML5
- CSS3 (responsive layout, CSS variables, animations)
- Vanilla JavaScript (mobile navigation, reveal-on-scroll, scroll progress, rotating role labels, email copy action)

## Before publishing

- Verify the education details, GPA, internship titles, dates, and certification names against your records.
- Replace any GitHub profile-level project links with the exact repository URLs for each project.
- Add your real LinkedIn profile URL if you want to display LinkedIn.
- Add a resume PDF only after confirming it is current and committed to the repository.
- Add model metrics only when you have measured them.
- Keep API keys, passwords, and private configuration out of the repository.

## Deploy with GitHub Pages

1. Push these files to the `main` branch.
2. Open repository **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to finish deployment. The URL appears in the Pages settings.

The homepage is named `index.html`, which is the standard entry-point filename for GitHub Pages. Replace the old `index.htm` file with this `index.html` rather than keeping both.
